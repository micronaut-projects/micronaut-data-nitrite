Table 1. Configuration Properties for NamedNitriteConfiguration
Property Type Description Default value

micronaut.nitrite.*.db-path

java.lang.String

Sets the db path.

micronaut.nitrite.*.username

java.lang.String

Sets the username.

micronaut.nitrite.*.password

java.lang.String

Sets the password.

micronaut.nitrite.*.storage-mode

NitriteConfiguration$StorageMode

Sets the storage mode.

micronaut.nitrite.*.sorted-read-strategy

NitriteConfiguration$SortedReadStrategy

Sets the sorted-read limit strategy.

micronaut.nitrite.*.field-separator

java.lang.String

Sets the field separator.

micronaut.nitrite.*.create-indexes

boolean

Sets whether to create indexes.

micronaut.nitrite.*.mvstore-page-split-size

java.lang.Integer

Sets the MVStore page split size in bytes.

micronaut.nitrite.*.mvstore-allowed-classes

java.lang.String

Sets additional JEP 290 patterns for stored application values.

micronaut.nitrite.*.mvstore-retention-time

java.lang.Integer

Sets the chunk retention time in milliseconds.

micronaut.nitrite.*.mvstore-versions-to-keep

java.lang.Integer

Sets the number of old versions retained.

micronaut.nitrite.*.mvstore-cache-size

java.lang.Integer

Sets the MVStore read cache size in MB.

micronaut.nitrite.*.mvstore-cache-concurrency

java.lang.Integer

Sets the MVStore read cache concurrency.

micronaut.nitrite.*.mvstore-auto-commit

java.lang.Boolean

Sets whether MVStore auto-commits.

micronaut.nitrite.*.mvstore-auto-commit-buffer-size

java.lang.Integer

Sets the MVStore auto-commit buffer size.

micronaut.nitrite.*.mvstore-auto-compact

java.lang.Boolean

Sets whether MVStore auto-compacts.

micronaut.nitrite.*.mvstore-compress

java.lang.Boolean

Sets whether MVStore compresses stored data.

micronaut.nitrite.*.mvstore-compress-high

java.lang.Boolean

Sets whether MVStore uses high compression.

micronaut.nitrite.*.mvstore-recovery-mode

java.lang.Boolean

Sets whether the store opens in MVStore’s recovery mode.

micronaut.nitrite.*.mvstore-read-only

java.lang.Boolean

Sets whether the store opens read-only.

micronaut.nitrite.*.mvstore-encryption-key

java.lang.String

Sets the MVStore encryption key.
