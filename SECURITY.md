# Security Policy

We release patches for security vulnerabilities. Eligible versions depend on the CVSS v3.0 rating:

| CVSS v3.0 | Supported Versions                        |
| --------- | ----------------------------------------- |
| 9.0-10.0  | Releases within the previous three months |
| 4.0-8.9   | Most recent release                       |

## Reporting a Vulnerability

Please disclose suspected security vulnerabilities privately to
**[The Micronaut Foundation](mailto:foundation@micronaut.io)**. Include the affected versions,
steps to reproduce the issue, and its potential impact. Do not disclose unpatched vulnerabilities
in public issues or pull requests.

You will receive a response within 48 hours. If the issue is confirmed, we will release a patch
as soon as possible depending on complexity; historically, this has taken a few days.
